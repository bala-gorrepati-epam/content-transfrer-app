## 1. xmc.contentTransfer.createContentTransfer

Environment: SOURCE. POST `/content/v1/transfers`. Success: 202 (transfer creation started, no body).

Params:
- `query.sitecoreContextId?: string` (source context ID)
- `body.transferId: string` (required, generated by us)
- `body.configuration.dataTrees?: Array<{ itemPath?: string; scope?: 'SingleItem' | 'ItemAndDescendants'; mergeStrategy?: 'OverrideExistingItem' | 'KeepExistingItem' | 'LatestWin' | 'OverrideExistingTree' }>`
  - `itemPath`: existing item path in the source environment, master database.
  - Casing is camelCase (a Postman sample used PascalCase, ignore it).

```ts
const transferId = crypto.randomUUID();
await client.mutate("xmc.contentTransfer.createContentTransfer", {
  params: {
    query: { sitecoreContextId: sourceContextId },
    body: {
      transferId,
      configuration: {
        dataTrees: selectedItems.map((item) => ({
          itemPath: item.path,
          scope: item.scope,
          mergeStrategy: item.mergeStrategy,
        })),
      },
    },
  },
});
```

The transfer is built asynchronously. Poll step 2 before fetching chunks.

  params: {

## 3. xmc.contentTransfer.getChunk

Environment: SOURCE. GET `/content/v1/transfers/{transferId}/chunksets/{chunksetId}/chunks/{chunkId}`. Success: 200, body is `Blob | File`.

Params:
- `path.transferId: string`
- `path.chunksetId: string` (lowercase "s" in `chunksetId`)
- `path.chunkId: number`
- `query.sitecoreContextId?: string` (source)

Response is binary. Keep it as a `Blob` and pass it unchanged to saveChunk.
Unverified: whether the Marketplace client returns it intact in the browser. Test one chunk first and check `blob.size > 0`.

```ts
const chunk = await client.mutate("xmc.contentTransfer.getChunk", {
  params: {
    path: { transferId, chunksetId, chunkId },
    query: { sitecoreContextId: sourceContextId },
  },
});
```

## 4. xmc.contentTransfer.saveChunk

Environment: DESTINATION. POST `/content/v1/transfers/{transferId}/chunksets/{chunksetId}/chunks/{chunkId}`. Success: 201 (no body).

Params:
- `body: Blob | File` (the chunk from step 3)
- `path.transferId: string`
- `path.chunksetId: string`
- `path.chunkId: number`
- `query.isMedia?: boolean` (default false; whether this chunk is media)
- `query.sitecoreContextId?: string` (destination)

Unverified: how to know whether a chunk is media. Leave `isMedia` unset unless known, and check the
Sitecore docs before copying media items.

```ts
await client.mutate("xmc.contentTransfer.saveChunk", {
  params: {
    path: { transferId, chunksetId, chunkId },
    query: { sitecoreContextId: destinationContextId },
    body: chunk,
  },
});
```

Save every chunk of a chunk set (and every chunk set) before step 5.

## 5. xmc.contentTransfer.completeChunkSetTransfer

Environment: DESTINATION. POST `/content/v1/transfers/{transferId}/chunksets/{chunksetId}/complete`. Success: 200.

Params:
- `path.transferId: string`
- `path.chunksetId: string`
- `query.sitecoreContextId?: string` (destination)

Response (PascalCase):
```ts
{ ContentTransferFileName: string }
```

Call once per chunk set after all its chunks are saved. Keep each returned name for steps 6 and 7.
Several chunk sets mean several files.

```ts
const done = await client.mutate("xmc.contentTransfer.completeChunkSetTransfer", {
  params: {
    path: { transferId, chunksetId },
    query: { sitecoreContextId: destinationContextId },
  },
});
```

## 6. xmc.contentTransfer.consumeFile

- `query.fileName: string` (required, full path of the `.raif` file, from step 5)

await client.mutate("xmc.contentTransfer.consumeFile", {

    query: {
      databaseName: "master",
